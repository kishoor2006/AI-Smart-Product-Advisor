# AI Smart Product Advisor
Flask web application for AI-based laptop recommendation, comparison and demonstration ordering.

Run:
`pip install -r requirements.txt`
`python app.py`

Open: http://127.0.0.1:5000

Product data and prices are sample/demo data. No real payment is processed. Orders are saved in SQLite. The recommendation engine is an explainable weighted decision/recommendation algorithm, not a trained ML model.
